# Zone 7 — Bar, Restaurant & Lounge

A complete, modern, high-end minimalist single-page website for Zone 7, located in Mbuya, Kampala, Uganda. Built with pure HTML, CSS, and vanilla JavaScript.

## Deployment to GitHub Pages

This repository is ready for GitHub Pages. To deploy:

1. Go to your repository on GitHub.
2. Navigate to **Settings** > **Pages**.
3. Under **Build and deployment**, set the source to **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click **Save**.

Your site will be live at `https://ojoklatim.github.io/zone7/` (or your custom domain).

## Features

- **Real Data**: Integrated TripAdvisor ratings and reviews.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Modern Aesthetic**: High-end minimalist design with charcoal and amber gold accents.
- **Interactive**: Scroll-triggered animations, mobile menu, and gallery effects.
- **SEO Ready**: Meta tags and Open Graph data included.

## Local Development

To run the site locally:

```bash
# Using Python
python3 -m http.server 8080
```

Open `http://localhost:8080` in your browser.
